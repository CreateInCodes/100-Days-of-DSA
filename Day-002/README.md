## Code practice

### Area of a circle

I wrote a program that asks the user for the radius and calculates the area of the circle.

Formula:

`area = 3.14 * radius * radius`

Example run:

```text
radius of circle: 10

area of circle is: 314
```

See [area_circle.cpp](./area_circle.cpp) for the code.
