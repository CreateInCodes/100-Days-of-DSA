# Day 01 — Getting Started with C++

## Today's goals

- [ ] Set up a C++17 compiler and editor.

- [ ] Practice output with `cout` and input with `cin`.
- [ ] Learn variables, basic data types, and arithmetic operators.
- [ ] Write a program to add two numbers.
- [ ] Write a program to calculate the area of a circle.

## Key concepts

- `#include <iostream>` provides standard input/output streams.
- Execution begins in `main()`.
- `std::cout` prints output; `std::cin` reads input.
- Common types: `int`, `long long`, `float`, `double`, and `char`.
- C++ statements usually end with a semicolon.
